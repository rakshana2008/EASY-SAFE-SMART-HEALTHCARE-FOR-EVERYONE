# Health Safety Loop

Health Safety Loop is a simple healthcare monitoring system designed to help users track basic health readings.

## Features
- Blood sugar monitoring
- Blood pressure monitoring
- Safety alerts for unusual readings
- Simple and easy-to-use interface

## Technology Used
- Python

## How to Run

1. Clone the repository.
2. Run the following command:

python app.py
